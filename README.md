# Linqode

A terminal UI (TUI) for managing remote servers over SSH, focused on monitoring
Docker Compose deployments: live service status, structured log analysis
(plain text and JSONL with real-time filtering and aggregation), and running
commands — all agentless, nothing to install on the server.

> **Status:** early development. The project was rebooted from scratch in July 2026;
> the previous static-analysis codebase has been removed.

See [docs/PROJECT.md](docs/PROJECT.md) for the project vision, MVP scope,
architecture, and technology choices.
